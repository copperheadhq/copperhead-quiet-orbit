# Project footprint reference

Unmodified copies of the stock KiCad 10.0.4 library footprints this board uses, kept in the
repository so that anything editing the board can read real pad geometry. The board keeps the
stock library ids (`Resistor_SMD:R_0603_1608Metric` and so on); these files are the same
definitions KiCad's DRC compares the board against. KiCad libraries are CC-BY-SA 4.0 with the
design-use exception.
