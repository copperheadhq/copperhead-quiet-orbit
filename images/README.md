# Images

These are renders, not photographs. No board has been made. They come from KiCad's raytracer
using generic 3D models from the standard library, not the exact manufacturer parts.

| Files | View |
|---|---|

| `03-`, `04-` | perspective from the ISP side |
| `05-`, `06-` | perspective from the USB side |
| `07-back-iso.png` | underside |
| `08-closeup-usb-input.png` | the input chain: connector, bulk cap, fuse, diode |
| `09-closeup-mcu-isp.png` | MCU, bypass, RESET pull-up and ISP header |
| `front.png`, `back.png`, `back-angle.png` | the Milky Way variant, purple mask and ENIG |
| `bare-top.png`, `bare-bottom.png` | the bare board with no parts fitted: pads, tracks, silkscreen and mask as a fab would deliver it |
| `bare-milkyway-back.png` | the Milky Way variant's back, bare, in purple mask with ENIG gold |
| `schematic.png` | the schematic sheet as KiCad plots it, with border, zone markers and title block. Same sheet as `docs/schematic.pdf` |
